# v2.2.0 中文版

CPU Set Setter 首个简体中文发行版，基于上游 2.2.0 系列代码，保留 CPU 集、处理器亲和性、核心掩码、快捷键和自动规则等功能。

## 本版内容

- 中文化进程、核心掩码、规则、设置页面，以及托盘菜单和主要提示。
- 提供简体中文安装界面、README、AMD 与 Intel 配置教程。
- 程序内的版本检查和发行页入口改为本中文仓库。
- 使用 .NET 10，提供 Windows x64 安装包、普通 ZIP 和内置运行时 ZIP。
- 附带项目及第三方许可证、源码提交链接和 SHA-256 校验文件。
- 配置自动构建及上游单向同步：上游更新先在本仓库合并、构建，通过后再合入 main；不会向上游推送代码或创建 PR。

## 下载哪个文件

| 文件 | 用途 |
| --- | --- |
| `CPUSetSetter_Installer.exe` | 安装版，简体中文安装界面；需要 .NET 10 Desktop Runtime |
| `CPUSetSetter_zh_win-x64.zip` | 免安装普通版；需要 .NET 10 Desktop Runtime |
| `CPUSetSetter_zh_win-x64_net10_included.zip` | 内置运行时，解压即可运行，无需另行安装 .NET |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值 |
| `SOURCE.txt` | 本次发行实际构建的源码提交链接 |

首次试用可选择内置运行时版。程序适用于 Windows x64；普通版和安装版缺少运行时时会提示安装 .NET Desktop Runtime。

## 汉化范围

本版已完成主要界面与常用提示的汉化，部分日志和少量选项仍保留英文，后续继续补齐。默认掩码名称和配置键沿用上游，以兼容已有配置。

上游标签不会直接复制成本项目的发行标签；本仓库 `v2.2.0` 对应包含中文化改动的源码。上游新增文本仍需后续翻译。
